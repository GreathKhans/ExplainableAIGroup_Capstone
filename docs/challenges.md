# Challenges

**Inactive one-hot columns.** The first SHAP view named dummy columns. For the saved notebook run, `checking_status_A14` carried a large positive value even though that code was false and the person was `A11`. Showing that bar as the reason would describe a checking account the applicant does not have. The screen sums dummies back to the original field and prints the value on the row.

**The two uploads were the same document.** Both files are P01–P08. Merging them would have doubled every clause and looked like a larger corpus. The text file is stored once. The official 89-page EBA report supplies the rest of the index. Search over that report does return the creditworthiness paragraphs, so the long file is doing real work.

**The draft invents facts.** Phi-3.5-mini was asked not to mention missed payments, income, or a numeric cutoff, and not to call the score a denial. It still sometimes does. The checks catch the phrases we have seen, and the interface leaves the warning next to the draft. We did not replace the model with a template, because the point of the draft is that a reviewer can see a generated text and reject it.

**Sex and foreign-worker comparisons are weak.** Sex is not separable from marital status in this table. The non-foreign group on the test split has nine people. Using either as the main fairness claim would overstate the evidence. Under 25 is the group we can describe, with the sample size on screen.

**The Colab metrics and the saved model differ.** An older notebook run reported ROC-AUC 0.8234 and a larger age gap. XGBoost 3.2 on this training recipe reports ROC-AUC 0.815 and a gap of −15.3 points. We did not overwrite the notebook outputs. The app and the committed model are one artifact, so the talk and the screen use those figures.

**No numeric cutoff was available to encode.** It is tempting to say, for example, that a renter's loan cannot exceed 24 months. EBA/GL/2020/06 does not set that number, and the project paraphrases do not either. Duration and amount stay in the chart as contributions and in the evidence column as "Needs verification".

**Line-break hyphens in the PDF.** The chunker joins a hyphen at the end of a line to the next line. That can glue a real compound into one word. Retrieval of the creditworthiness paragraphs still succeeded, so the chunker was left as it is rather than hand-editing the official text.
